# ANB Advisors LLP — Website

Production-ready Next.js 14 site for ANB Advisors LLP (Strategic Finance &
Corporate Advisory). Built with TypeScript, Tailwind CSS, and Framer Motion.

## Quick start

```bash
npm install
cp .env.example .env.local   # edit with your real values
npm run dev
```

## Documentation

- **[GUIDE.md](./GUIDE.md)** — placeholder checklist, how the lead-capture
  forms + database work, database swap instructions for serverless hosting,
  and step-by-step deployment (Vercel / VPS+Docker / Netlify).
- **[GTA&SEO.md](./GTA&SEO.md)** — SEO checklist for Google/Bing/DuckDuckGo,
  and a full GTM + GA4 connection walkthrough, including a map of every
  analytics event already wired into the site.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the local dev server |
| `npm run build` | Production build |
| `npm run start` | Run the production build locally |
| `npm run lint` | Lint the codebase |
